## 実装済み・運用方針
- **通常編集は既存OSMオブジェクトのタグのみ。** 地図ラベルが保持する元のOSM type（node/way/relation）・ID・タグを編集する。node/way/relationそのものの新規追加、座標・形状・参照ノード・メンバーの変更は通常編集の対象外。OSM要素種別の選択欄は現在テスト用UIにあり、通常利用者向けの自動判定化は将来案で未実装。
- ラベル編集はタグの追加・削除・変更をUIで行い、**「確認」でJSONの差分と全タグを表示する**。未送信の編集内容は保存しない（タグ下書きのlocalStorage保存なし、画面を閉じる/リロードで破棄）。既存の確認画面は保持。
- **OSM本番からテスト環境への新規コピーは検証専用の例外として維持。** 本番OSMは公開GETで読むだけ。node/wayがコピー対象、relationコピーは未対応。wayは構成ノードを含めてテスト側に新規登録。コピーにはテスト環境向けOAuth（PKCE / write_api）とチェック確認が必要。本番OSMの編集APIへの書き込みは実装していない。
- **テストAPIでのタグ送信は既存の店舗・施設オブジェクトへの `level` 新規追加だけ**（`level=0〜8` が1〜9階）。テスト要素に店舗・施設タグがあり `level` が未設定の場合に限る。既存のversion・geometry等を保持し、changeset作成→PUT→close。既存 `level` の更新・削除、他タグ送信、複数タグの一括送信は未実装。
- **テスト対象の指定欄:** 要素種別（node/way/relation）→テストサーバーの店舗・施設ID→「テスト対象を読み込む」の順。IDは数字のみ、`node/ID`、テストOSMの要素URLを受け付ける。コピー後の新規IDは送信欄へ引き継ぐ。
- **結果フィードバック:** コピー成功は「確認してコピーを作成」ボタン直下に、松戸ワールド選択に合わせた緑枠（背景 `#d9ebd5`、枠 `#64956c`、文字 `#31563b`）で、新規ID・changeset ID・要素リンクを表示。読み込み・送信・認証・コピー準備/実行失敗は赤系の枠。コピーの前提不足時は理由を表示し、処理中・成功済みの再実行を無効化。
- **changeset自動コメント（直近追加）:** 変更前後のタグを比較して1変更タグにつき1行。例：単独 `add - level : 2`、`delete - old_name`、`update - level : 2 → 3`。複数変更時のみ操作名の最大幅に合わせ、`add    -` / `delete -` / `update -` とハイフン位置を整列。OSM changesetの `comment` に設定する。利用者向けのコメント表示・編集・専用確認画面は**設けない**。現行送信はlevel新規追加のため、実際に送られるのは単独add形式。コピー用changesetの説明文は従来のまま。
