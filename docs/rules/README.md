## 新しい開発チャットでの確認順

1. **この目次と基本3ルールファイル**を読む。地図タイル分割に関わる場合は `map-tiles.md` も読む。
2. [STATUS.md](../STATUS.md) から現在の状況・未完了タスク・変更禁止資材を確認する。
3. 作業に必要なファイルを、GitHub `main` の**最新ソース**から確認する。
4. ユーザーが指定した今回の作業を優先し、完了済み工程を勝手にやり直さない。

**役割の分離：** ルールはここ、現在地は `STATUS.md`、プログラムの現在値はGitHub `main` の実コードが正本。

**変更方針：** ルールの変更はユーザーと文言を確認し、明示的な了承後にコミットする。 `STATUS.md` の定期更新でルールファイルをまとめて書き換えない。
