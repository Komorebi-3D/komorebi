# 🌳 チャット・質問フォームの運用ルール

対象：原則「00｜統合開発」チャット。ユーザーが別の形式を指定した場合は、その依頼を優先する。

## 質問の基本形

- **`Q〇〇. 質問内容` → ラジオボタンの回答候補 → その設問のコメント欄（任意）**を基本形とする。
- **質問が複数ある場合**は、それぞれQ番号を付け、**1つの回答フォーム**にまとめる。最後に**送信ボタンを1つ**置く。
- 送信時は全設問の選択結果とコメントを**Q番号付きの1回のチャットメッセージ**として返せるようにする。
- コメントは空欄でも送信可能。質問は必要な数に絞り、関係のない確認を増やさない。
- 単独質問でも同じ基本形を使う。チャット内で操作できるラジオ等を優先する。

## Q番号

- **同じチャットでは番号を順番に進める**。
- 新しい「00｜統合開発」チャットを作り直した場合は**Q1から開始してよい**。以前のチャットの最後の番号を引き継ぐ必要はない。

## 引き継ぎ

- 新しい開発チャットでは [ルール目次](README.md) の各文書と [STATUS.md](../STATUS.md) を確認する。
- 現状やソースに関わる判断では、過去チャットの記憶だけに頼らず、GitHub `main` の最新の関連ソースを確認する。
- ユーザーがすでに答えた条件・PASS結果を、理由なく再質問しない。
