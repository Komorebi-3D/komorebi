# 🌳 チャット質問ルール

対象：「00｜統合開発」

## 1. 質問の形式

質問するときは、以下のサンプルと同じ形式で、**チャット内で操作できる質問フォーム**を表示すること。

### サンプル

**Q1. 建物の色はどうしますか？**

◉ A｜白

◯ B｜茶色

◯ C｜グレー

◯ D｜その他

**💬 コメント（任意）**

［自由入力欄］

**［回答を送信］**

## 2. 運用ルール

- 回答はラジオボタンで選択する。
- 各質問に任意のコメント欄を設ける。
- 複数の質問は1つのフォームにまとめる。
- 送信ボタンは最後に1つだけ設置する。
- 回答とコメントはQ番号付きでチャットに送信する。

## 3. Q番号の管理

- **新しいチャットではQ1から開始する。**
- 同じチャット内ではQ2、Q3、Q4…と順番に進める。
- 過去チャットのQ番号は引き継がない。
- Q番号の確認のために `STATUS.md` やGitHubの記録を参照する必要はない。
